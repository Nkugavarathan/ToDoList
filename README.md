# 📝 Todo List App

A beautiful and functional Todo List application built with **React**, **useReducer**, and **Bootstrap**.

---

## 📸 Screenshot

![Todo App Screenshot](./src/assets/home.JPG)



---

## 🚀 Features

- Add, delete todos
- Move todos up ⬆️ and down ⬇️
- Uses `useReducer` for clean state management
- Styled with Bootstrap for a modern look

---

## 🧠 Tech Stack

- ⚛️ React
- 🧮 useReducer Hook
- 🎨 Bootstrap 5
